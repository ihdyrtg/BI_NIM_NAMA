# M07 Bookmark Setup

1. Executive page: create `Penjualan per Bulan` and `Laba per Bulan` visuals in the same position/size.
2. Open **View > Selection** and **View > Bookmarks**.
3. Show Penjualan, hide Laba -> Add bookmark -> rename `Fokus Penjualan`.
4. Open bookmark options and turn **Data off** when the bookmark should only preserve visibility, not filters/slicers.
5. Show Laba, hide Penjualan -> Add -> `Fokus Laba` -> Data off.
6. Insert **Bookmark navigator** and expose only those two bookmarks.
7. Select a non-default Year/Branch/Channel, switch bookmark, and confirm the slicer selection stays unchanged.

Do not mark this QA as passed until it has been tested in Power BI Desktop.
