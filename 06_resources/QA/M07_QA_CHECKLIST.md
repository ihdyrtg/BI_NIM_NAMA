# M07 Quality Assurance

- [ ] Executive memiliki 4 KPI, tren, dan perbandingan cabang.
- [ ] Product & Campaign memiliki analisis produk, kategori, kampanye, dan slicer.
- [ ] Branch & Customer memiliki perbandingan cabang dan segmen pelanggan.
- [ ] Page Navigator berpindah ke tiga halaman utama.
- [ ] Branch Detail menerima filter Branch_Name dan menampilkan daftar transaksi.
- [ ] Back button pada Branch Detail berfungsi.
- [ ] Tooltip Product tampil saat hover dan mengikuti produk.
- [ ] Branch Detail dan Tooltip Product hidden dari navigasi utama.
- [ ] Bookmark Fokus Penjualan / Fokus Laba tidak mereset slicer secara tak diinginkan.
- [ ] 5-second test dicatat dari tester nyata.
- [ ] Minimal satu revisi dilakukan dari hasil tes.
- [ ] Format angka, judul, font, warna, dan jarak konsisten.
